# Northstar — Startup Operating System

Northstar is a hackathon-ready operating command center for startup founders. It connects company metrics, initiatives, team capacity, pipeline signals, and AI-assisted decisions in one responsive interface.

## Included

- Founder command center with live health metrics
- Persistent Cloudflare D1 database with seeded demo company data
- AI-style daily briefing and contextual business Q&A
- Decision queue with approval actions saved to the database
- Goals, CRM, Team, and Reports workspaces
- Responsive desktop and mobile interface

## Run locally

```bash
pnpm install
pnpm dev
```

The database tables and demo dataset initialize automatically on first use.
